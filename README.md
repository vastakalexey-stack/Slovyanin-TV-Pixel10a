# Славянин ТВ

Android-приложение для Pixel 10a (Android 8.0+). Тёмный интерфейс, добавление пользовательских M3U/M3U8-плейлистов по URL и импорт локального файла, категории, избранное и воспроизведение через AndroidX Media3.

## Сборка
Откройте проект в Android Studio или запустите GitHub Actions workflow **Android APK**. APK появится в артефактах workflow под именем `Slovyanin-TV-debug`.

Проверка сборки запускается автоматически при отправке изменений в `main` и при создании pull request в `main`.

## Источники каналов
Приложение не содержит нелицензионных списков каналов. Добавляйте плейлисты, на использование которых у вас есть права или подписка. Доступность трансляций зависит от источника и региона.
